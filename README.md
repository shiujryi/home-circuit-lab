# 家用配電實驗室

台灣住宅配電概念學習網頁。第一版包含 110V 接地插座、單切開關與雙切開關三個互動單元，以電風扇和電燈作為測試負載。所有互動皆在瀏覽器內執行，可直接用 GitHub Pages 發布。

## 本機預覽

在專案目錄執行 `python -m http.server 8765`，然後開啟 `http://127.0.0.1:8765/`。

## GitHub Pages

將此目錄推送到專用儲存庫的 `main` 分支，再於儲存庫 Settings → Pages 選擇從 `main` 分支的根目錄發布。

## 圖片與資料

網站直接引用商品頁提供的 WTDFP15123 與 WTDFP5152K 正、背面照片網址，來源記錄於 `sources.html`。照片上的端子標記為網站額外顯示的學習標記。端子圖為概念練習，實際產品以原廠標示和說明為準。
